# Save My Daily Day

**Description:**  
ใช้บันทึกไดอารี่รายวัน เน้นสร้างนิสัย ใช้งานง่ายสำหรับคนมีเวลาน้อยและใช้แบบขี้เกียจๆ ออกแบบเพื่อทุกคนที่อยากบันทึกแต่ไม่อยากยุ่งยาก

---

## Requirements / วิธีติดตั้ง

1. **เพื่อใช้งานโปรแกรม:**  
ดาวน์โหลดไฟล์โปรแกรมได้ด้านล่าง (สามารถเลือก .zip หรือ .rar)

2. **สำหรับดูโค้ดหรือปรับแต่ง:**  
ต้องติดตั้ง Python เวอร์ชันล่าสุด และไลบรารีที่อยู่ใน requirements.txt
วิธีรัน: 
```bash

pip install -r requirements.txt
```

**ดาวน์โหลดไฟล์โปรแกรม:**  
- [Download ZIP](https://zippyshare.day/rEhmpxIjpbY1dKC/file)  
- [Download RAR](https://zippyshare.day/6wqyYvDq5ln3rHf/file)  

---

## ตัวอย่างการใช้งาน

รันโปรแกรม:

```bash

python main.py
```
